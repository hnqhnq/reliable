## 0. 目标与定位

**当前阶段（已做）：论文复现。**
1. 复现 **C²BM**（GES + LLM/RAG 边定向 → 因果概念瓶颈模型）与 **BC-LLM**（LLM 提议/标注概念 + split-sample Metropolis 的贝叶斯概念搜索）的核心结果，确认代码、环境与论文数值可对上。
2. 论文用 GPT-4o / GPT-4o-mini，本机无 OpenAI API。因此把 LLM 换成国产 API（Qwen、DeepSeek）并判断**替代是否成立**。该部分属于“替代模型实验”，不是 GPT-4o 原结果的重跑。

**后续阶段（未做，仅有设计）：方向 2——把 BC-LLM 的 split-sample MH 机制迁移到 C²BM 的因果边定向。**
动机（文献汇报 Gap-2）：C²BM 对每条无向边只让 LLM 重复投票 10 次取多数，没有数据层面的纠错。当 LLM 背景知识有偏时，多数投票无法发现错误。当前复现工作是该方向的基线与代码基础。

## 4. 后续研究设计：方向 2（split-sample 迁移到边定向）

**状态：仅设计，尚未实现。**

### 4.1 问题形式化

- 对象：CPDAG 中的每条无向边 e，状态 z_e ∈ {A: i→j, B: j→i, C: 无边}，与 C²BM 的三选项一致。图配置记为 G = (z_e)。
- 现状（基线）：LLM + RAG 对每条边投 10 票取多数，没有数据纠错。
- 目标：用 BC-LLM 的 split-sample 思路，让 LLM 提议方向、让未参与提议的数据决定是否接受。

### 4.2 算法草案（单边更新，Metropolis-within-Gibbs）

1. 每次更新随机划分数据 D = D_S ∪ D_S^c，比例 ω = 0.5。
2. **提议**：LLM + RAG 在看到 D_S 的摘要（如条件独立检验结果、少量样本）后，对边 e 给出候选方向 z'_e。每次一票，用较高温度采样，不再投 10 票。
3. **接受**：用 D_S^c 计算偏 Bayes 因子，α = min{1, p(D_S^c | D_S, G') / p(D_S^c | D_S, G)}，与 BC-LLM 的接受率同构。
4. 迭代 T 轮，对各边方向取后验频率；最终图取后验众数，也可保留边级后验作为不确定性输出（对应 Gap-3）。

### 4.3 关键风险：观测数据区分不了同一马尔可夫等价类内的方向

CPDAG 的无向边在同一等价类内是得分等价的，对线性高斯或 BDeu/BIC 打分，两个方向的 p(D_S^c | …) 相同，α 恒为 1，数据没有纠错能力。可选的应对：

| 方案 | 做法 | 代价 / 问题 |
|---|---|---|
| a（首选） | 用 C²BM 的神经 SCM（超网络）在 D_S^c 上的**留出似然**作为 p(D_S^c | …) | 神经网络不严格得分等价，会产生差异，但差异是否反映真实方向需实验验证 |
| b | 允许提议 C（删边）或改变 v-structure，使 MEC 改变，BIC 才有区分度 | 只能纠正“边存在性”类错误 |
| c | 使用含干预样本的数据 | Asia 等基准可模拟，真实数据通常没有 |

这是需要与导师讨论的核心问题：方案 a 若无法区分方向，方向 2 的实证结论会很弱，应尽早用 pilot 验证。

### 4.4 实验设计

**Pilot（约 1 周，先做）**：Asia（边少、已有共用 CPDAG 与完整训练流水线）。目的：验证方案 a 的留出似然在“错误方向 vs 正确方向”上是否有可测差异。通过标准：正确方向的留出似然在多数划分下高于错误方向。未通过则转方案 b/c，或改做方向 4。

**主实验**：

| 编号 | 内容 | 对比 | 指标 |
|---|---|---|---|
| E1 | 在 Asia、Sachs 上比较三种方法：GES 仅用 / C²BM 多数投票 / 本方法 | 同一 CPDAG、同一 LLM、**相同 API 预算** | SHD（Appendix F.1 非对称 SHD）、错误边数、下游准确率（5 seed，均值 ± 2SEM）、API 调用数 |
| E2 | **鲁棒性（核心卖点）**：向 RAG/提示注入有偏背景知识，或换更弱模型 | 多数投票 vs 本方法 | 错误是否被纠正；SHD 随偏差强度的变化曲线 |
| E3 | 消融 | 划分比例 ω、迭代轮数 T、是否使用 RAG、接受得分方案 a/b | 同 E1 指标 |
| E4 | 经验收敛检查 | 多条独立链 | 接受率、各边后验在不同链间的一致性（如 R-hat） |

**成功判据**：E1 中 SHD 不劣于多数投票；E2 中偏差注入下显著优于多数投票；E1 的 API 成本在同一量级。
**理论**：收敛性证明列为后续工作，若证明困难则退化为纯实证（文献汇报已列该风险）。

**复用的现有资产**：共用 GES CPDAG、`requests.jsonl` 调用日志、RAG 缓存、断点续跑脚本、Asia 五 seed 训练脚本。需新增的部分：边级 MH 循环、留出似然评估、偏差注入。

## 7. 两篇论文的理论与思想（通俗版）

### 7.1 共同背景：概念瓶颈模型（CBM）

CBM 把预测拆成两步：**输入 X → 一组人能看懂的概念（如"有咳嗽""翅膀偏黄"）→ 结果 Y**。好处是可解释、可人工纠错（发现概念判错了，改掉再预测）。它留下两个问题，两篇论文各解决一个：

| 问题 | 论文 | 一句话 |
|---|---|---|
| ① 该选**哪些概念**？ | BC-LLM | 让 LLM 想概念，让数据来把关 |
| ② 概念之间**怎么连**？ | C²BM | 按因果图连，而不是全部平铺连到 Y |

两篇互补：BC-LLM 不管概念之间的关系，C²BM 不管概念怎么选。

### 7.2 BC-LLM 的思想

**要解决的难点**：概念是自然语言，候选近乎无限，不能像普通变量选择那样逐个试；LLM 能提出有意义的候选，但会"一本正经地胡说"。

**核心思路：LLM 当"点子王"，数据当"裁判"，而且裁判不能是出点子时看过的数据。**

- **贝叶斯视角**：不追求唯一的"最优概念集"，而是得到**一批概念集合的后验样本**（哪些概念组合都说得通），因此能说清"哪些概念确定、哪些不确定"。
- **Split-sample（样本切分）**：每次更新一个概念时，随机把数据分成两半。LLM 只看 A 半数据的摘要来提议新概念；B 半数据（LLM 没见过）决定接受还是拒绝。
  - 如果 LLM 看了全部数据，它的建议天然"贴合"数据，裁判形同虚设，错误无法被发现。
  - 如果 LLM 完全不看数据，提的概念大多无关，浪费调用。
  - 切分是两者折中：既利用 LLM 对数据信号的判断，又保留独立检验。类比：同学出题（看过练习册）+ 老师用另一套卷子考。
- **Multiple-try（多候选）**：一次让 LLM 给 M 个候选，按在 B 半数据上的表现挑一个，再做接受判断。省 API（候选可在同一次提示里批量标注），也更容易换到好概念。
- **最终预测**：每个概念集合配一个简单逻辑回归，最后把多条链上的模型集成；概念的置信度来自"它在后验样本里出现的频率"。

**理论保证（要诚实地读）**：
1. 只要 LLM 的提议满足理想条件，这条链最终会按正确的后验分布采样（有限样本也成立）。
2. 即使 LLM 不完美，样本足够多时，概率会集中到"预测上最好的概念集"。前提是：**LLM 有一定概率能提到关键概念**。LLM 永远想不到的东西，数据裁判也变不出来。
3. 不要过度解读：这是渐近结果，小样本和 T=5 的短链不保证收敛；找到的是"预测最优"的概念，不等于真实因果因素。

### 7.3 C²BM 的思想

**要解决的难点**：普通 CBM 把所有概念都当作 Y 的直接原因，会给出误导性的解释（例如"咳嗽 → 肺癌"，实际咳嗽是症状而不是原因）。人工纠错时，改一个上游概念也不会影响其他相关概念。

**核心思路：先弄清概念之间谁导致谁，再按这张图推理。**

1. **找骨架（GES）**：从数据学出概念间的关系，但仅凭观测数据，有些边的方向分不出来（多种因果图在数据上不可区分，称 Markov 等价类，得到的是"部分有向图" CPDAG）。
2. **定方向（LLM + 检索）**：只对**无向的边**，让 LLM 结合检索到的资料回答"A 导致 B / B 导致 A / 无边"，重复 10 次取多数。这是用**背景知识**补上数据给不出的那一点信息。
3. **按图推理（神经结构因果模型）**：每个概念只由它的"父概念"算出来，沿图从根到目标逐层传播。为了表达力，各边的权重不是固定的，而是由小网络（超网络）根据当前输入**动态生成**。形式上是线性、权重随输入变化，所以整体仍很灵活。
4. **干预**：人工把某个概念改成真值，效果会顺着图传到下游，不再是"改一个没别的变化"。训练时也随机替换一部分概念为真值，让模型习惯被纠正后的输入。

**理论与警告**：
- 有表达力证明：只要网络足够大，无论图是什么，都能逼近任何输入到概念的映射。
- 副作用：**准确率高不能证明图对**，图被打乱后准确率几乎不变（论文消融也如此）。所以审核图必须单独看 SHD、干预效果、路径效应。
- 论文不声称恢复真实的结构方程，只声称"可信图 + 数值近似"足以支持概念层面的干预；也不单独解决 OOD，只是让人工纠错更有效。

### 7.4 两篇论文的"关键共性"与我们方向 2 的出发点

| 维度 | BC-LLM | C²BM |
|---|---|---|
| LLM 的角色 | 提议新概念 + 标注 | 判断边的因果方向 |
| 有没有数据来纠 LLM 的错 | **有**（B 半数据做接受/拒绝） | **没有**（10 票取多数，错了就是错了） |
| 不确定性 | 概念集合的后验 | 无（只给一张确定的图） |

这正是方向 2 的动机：**把 BC-LLM 的"LLM 提议 + 独立数据裁判"搬到 C²BM 的边定向上**，让 LLM 的背景知识有数据把关，并给每条边输出后验不确定性。主要难点在 §4.3：同一等价类内两个方向在数据上得分相同，需要借助神经 SCM 的留出似然等方式来区分。
