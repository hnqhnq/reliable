# 方向 2：Asia 接受得分 Pilot 实验设计

**状态**：**Phase 0 已跑完（2026-11-20），方案 a 未通过** — 结论见 [`report/20261121方向2-Asia-Pilot-Phase0结论.md`](20261121方向2-Asia-Pilot-Phase0结论.md)

**编写目的**：在实现完整 Metropolis-within-Gibbs 边定向之前，用约 1 周时间验证 **方案 a**——用 C²BM 神经 SCM 在留出集 \(D_S^c\) 上的似然能否区分「正确 vs 错误」的边方向。

---

## 1. 背景（给导师的 30 秒版）

C²BM 在 CPDAG 上对每条无向边用 LLM 投 10 票定方向，**数据不参与纠错**。方向 2 拟借鉴 BC-LLM：LLM 只在子集 \(D_S\) 上提议，**独立留出集 \(D_S^c\) 决定是否接受**。  
难点在于：对经典结构学习得分（BIC/BDeu），马尔可夫等价类内两个方向得分相同，接受率会退化为 1。**方案 a** 用我们已会训练的 C²BM 超网络，在 \(D_S^c\) 上算留出负对数似然（与训练中的 `val_loss` 同量纲）作比较。  
**本 Pilot 不问「能否超过 10 票基线」**，只问：**正确方向是否在多数随机划分下留出似然更好？** 若答案是否定的，应尽快与导师决定转方案 b/c 或方向 4，避免投入完整 MH 工程。

## 2. 科学问题与假设

| 项目 | 内容 |
|------|------|
| 零假设 \(H_0\) | 对 CPDAG 中每条无向边 \(e\)，在等价类允许的两种定向下，\(D_S^c\) 上神经 SCM 留出似然 **无系统差异**（或差异与真方向无关）。 |
| 备择 \(H_1\) | 在 **真方向** 下训练的 SCM，在 \(D_S^c\) 上的留出似然 **显著更优**（更低 `val_loss` / 更高对数似然）的比例 **> 50%**（可设更严阈值，见 §5）。 |
| 不检验的内容 | LLM 提议质量、MH 链收敛、SHD 是否优于 10 票——留到 Phase 1+。 |

## 4. 实验协议

### 4.1 Phase 0：Oracle 方向判别（**本周优先**）

**目的**：在 **已知正确/错误方向** 两种设定下，仅比较方案 a 的留出似然，排除 LLM 噪声。

对 CPDAG 中每条无向边 \(e=(i,j)\)（邻接矩阵中 `[i,j]=[j,i]=-1`）：

1. **构造两张仅差该边方向的 DAG** \(G^{+}\)（真向）、\(G^{-}\)（反向）；其余边与当前 **completed DAG** 或 pilot 专用「除 \(e\) 外均按真图定向」模板一致（见 §4.4 实现备注）。
2. 重复 \(R\) 次（默认 **\(R=30\)**）：
   - 随机 seed \(s\)，将 \(n=10000\) 样本按 **\(\omega=0.5\)** 划分为 \(D_S\) 与 \(D_S^c\)（与 BC-LLM 划分比例一致）。
   - 在 **\(D_S\)** 上各训练一次 C²BM（**短训**：`max_epochs=80`，`patience=15`，其余超参与 `run_c2bm_asia_api.sh` 一致），固定随机种子 \(s\) 以保证可复现。
   - 在 **\(D_S^c\)** 上评估 **平均 `val_loss`**（或等价留出 NLL），记 \(\mathcal{L}^{+}_s\)、\(\mathcal{L}^{-}_s\)。
3. 单边判决：\(\Delta_s = \mathcal{L}^{-}_s - \mathcal{L}^{+}_s\)（>0 表示真向更好）。
4. 汇总边 \(e\) 的 **win rate** \(w_e = \frac{1}{R}\sum_s \mathbf{1}[\Delta_s > 0]\)。

**记录**：`runs/direction2/asia_pilot_phase0/summary.csv`（列：边、\(w_e\)、平均 \(\Delta\)、标准差、是否通过单边阈值）。

### 4.2 Phase 1：LLM 提议 + 同一接受得分（Phase 0 通过后）

在相同 \((D_S, D_S^c)\) 划分下：

1. **提议**：对边 \(e\) 调用现有 RAG+LLM **1 票**（高温），替代 10 票多数（与 §4.2 方向 2 草案一致）。
2. **接受**：若提议为 \(z'_e\)，与当前 \(z_e\) 比较，用 Phase 0 同款留出似然比构造 \(\alpha = \min\{1, \exp(-(\mathcal{L}'-\mathcal{L}))\}\) 或论文同构的偏 Bayes 形式（实现时与 BC-LLM 接受率对齐）。
3. 指标：提议方向与真向一致时接受率、与反真向一致时拒绝率；**API 预算** \(\ll\) 10 票基线。

Phase 1 **依赖** Phase 0 证明留出似然对方向有信号；否则不启动大规模 API。

### 4.3 划分与训练对齐 BC-LLM

| 参数 | 值 | 理由 |
|------|-----|------|
| \(\omega\) | 0.5 | 与 BC-LLM split-sample 一致，便于叙事与后续联合论文。 |
| \(R\) | 30（可调 20–50） | Asia 边数少，总训练次数 = \(2 \times |E_{\text{undir}}| \times R\)。 |
| Batch / 样本量 | 与现 Asia 脚本相同 | 避免混入额外 confound。 |
| LLM 投票 | Phase 0：**0**；Phase 1：**1/边/划分** | 成本控制。 |

## 5. 通过 / 未通过标准

### 5.1 方案 a 可行性（Phase 0）

| 级别 | 条件 | 解读 |
|------|------|------|
| **强通过** | 所有无向边 \(w_e \geq 0.7\)，且整体平均 \(w \geq 0.75\) | 可放心实现完整 MH + E1 主实验。 |
| **弱通过** | 平均 \(w \geq 0.6\)，且 **错误 LLM 定错的那条边**（若已知）\(w_e \geq 0.6\) | 可与导师讨论后进入 Phase 1，主文强调「数据可纠错」需更多数据集。 |
| **未通过** | 平均 \(w \leq 0.55\) 或多条边 \(w_e \approx 0.5\) | **停止** 方案 a 主线；会议选型：**b**（删边/改 v-structure）、**c**（干预数据），或 **方向 4**（仅不确定性输出、不改接受规则）。 |

统计检验（可选汇报）：对每条边做符号检验或 bootstrap；导师汇报可先给 **win rate + 置信区间**。

### 5.2 与下游 SHD 的关系

Phase 0 **不要求** 重新计算 SHD。留出似然是可接受得分的 **必要前提**；若 Phase 0 失败，SHD 改善无从谈起。
