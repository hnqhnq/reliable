## 4. Hailfinder 并行异常与处理

- 最初将 Hailfinder seeds 2–5 放在同一 GPU 并行训练，虽然均正常退出，但 seeds 3/4 分别只有 62.20%/62.60%。
- 使用完全相同的 seed 3 缓存数据独占 GPU 重跑后得到 72.10%，相差 9.90 个百分点，说明该设置对同卡多进程的数值非确定性敏感。
- 正式统计使用五个无 GPU 竞争的串行结果：73.60%、74.50%、72.10%、71.85%、70.35%。没有挑选或删除预定 seed。
- 异常并行结果保留为 `metrics_parallel_diagnostic.csv` 和 `summary_parallel_diagnostic.csv`，但不进入论文复现汇总。

串行补跑目录：`runs/c2bm/hailfinder_true_graph_serial_5seeds_2026-10-02`。
