## 4. 本机：打包命令（推荐 tar → `tmp_doc` → scp）

默认本机仓库：`/home/src/Reliable`。若路径不同，全文替换即可。

### 4.1 C²BM 虚拟环境（必传，体积通常 **3–6GB+**）

```bash
cd /home/src/Reliable
mkdir -p tmp_doc

tar -czf tmp_doc/upload_c2bm_venv.tar.gz -C .venvs c2bm
ls -lh tmp_doc/upload_c2bm_venv.tar.gz
```

### 4.2 C²BM 实验产物 `runs/c2bm`（强烈建议）

```bash
cd /home/src/Reliable

# 含日志；若体积过大可去掉日志：

#   --exclude='*.log' --exclude='hydra' \
#   asia_predicted_shared_seed1 asia_predicted_qwen_seed1 asia_predicted_deepseek_seed1
```

### 4.3（可选）C²BM 缓存

```bash

```

### 4.4 上传到云 `tmp_doc/`

把 AutoDL 控制台里的 **SSH 端口** 和 **主机** 代入：

```bash

scp -P <端口> \
  upload_c2bm_venv.tar.gz \
  upload_c2bm_runs.tar.gz \
  root@<AutoDL主机>:/root/autodl-tmp/projects/reliable/tmp_doc/
```

若还有 `upload_c2bm_runs_minimal.tar.gz` 或 `upload_cache_c2bm.tar.gz`，一并 `scp` 即可。

**说明**：现有 `unpack_staging_from_tmp_doc.sh` **只识别 BC-LLM / CUB**，**不识别** `upload_c2bm_*`。请在云上按 **§5 手动解压**（或你解压后让我把规则写进该脚本）。

## 9. 体积与耗时粗估

| 包 | 粗估大小 | 备注 |
|----|----------|------|
| `upload_c2bm_venv` | 3–6 GB+ | 取决于 conda/pip 与 CUDA 轮子 |
| `upload_c2bm_runs`（完整） | 数十 MB～数 GB | 若含 `hydra/checkpoints` 会明显变大 |
| `upload_c2bm_runs_minimal` | 通常 &lt; 50 MB | 仅 shared + 单 provider seed1 |
| `upload_cache_c2bm` | 视本机而定 | 可选 |
